# Stoffabgleich Mitarbeitergespräche · Buchkapitel 2

Grundlage ist der bereitgestellte DIHK-Textband *Führung und Zusammenarbeit* für Wirtschaftsfachwirte. In diesem Kapitel entsprechen die PDF-Seiten 24–36 den gedruckten Seiten 31–43. Zu Aufgabe 3 wurden zusätzlich die zugehörigen Lösungshinweise auf PDF 99–100 (Druck 112–113) abgeglichen.
