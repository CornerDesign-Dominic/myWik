# myWik 0.11.1 für Android

MeiWik kann Fragen zu allen 699 mitgelieferten Artikeln und ihren Abschnitten beantworten. Der Cloud-Katalog enthält jetzt auch die Artikel aus BWL, VWL, Steuern, Unternehmensführung sowie Investition und Finanzierung.

In der Android-Testversion findest du das Update unter **Einstellungen → App-Updates → Nach Updates schauen**. Die KI-Funktion benötigt eine Internetverbindung und ein freigeschaltetes Konto.
