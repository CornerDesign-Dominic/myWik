# myWik 0.11.0 für Android

Diese Version ergänzt 106 Lernartikel in BWL, VWL, Steuern, Unternehmensführung sowie Investition und Finanzierung. Der Offline-Katalog enthält jetzt 699 Artikel und 1.314 Glossarbegriffe. Die fünf Fächer bieten Anwendungsbeispiele, Übungsfragen und aufklappbare Musterantworten.

Öffne in der installierten Android-Testversion **Einstellungen → App-Updates → Nach Updates schauen**. Lade das Paket für 0.11.0 herunter und wähle beim Öffnen der APK **Aktualisieren**.
