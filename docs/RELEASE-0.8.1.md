# myWik 0.8.1 für Android

Unter **Einstellungen → App-Updates → Nach Updates schauen** zeigt myWik, ob eine neuere Version verfügbar ist. Mit **APK herunterladen** lässt sich die Datei direkt öffnen und anschließend über Android installieren.

Installiere 0.8.1 direkt über die vorhandene myWik-App und wähle **Aktualisieren**. Lass die App dabei installiert, damit deine Notizen und Karteikarten erhalten bleiben.
